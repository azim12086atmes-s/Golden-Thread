## Conflict resolutions

- C-01: Old CLAUDE.md prohibits all facial features; owner explicitly adds glasses/beard/hair. Allow those exact additions while retaining no eyes and the existing exclusions for nose/mouth/eyelids. Do not infer permission for an expressive face. Beard is attached to floating head, never torso.
- C-02: Current travel menu constructs vehicles at the player. GT-VEH-001 supersedes that behaviour. Keep it marked unmet until all boarding, saving, map travel and recovery paths use persistent instances.
- C-03: Necessities could contradict the peaceful no-fail-state design. Design interpretation: comfort/readiness and planning costs, community meals and work exchanges; no death, confiscation, affection loss or mandatory grind. This interpretation is adjustable; it is not an extra owner quotation.
- C-04: Cities must feel large, but the existing 700-unit grid is a prototype. Build and benchmark a dense route slice before enlarging all regions. Land count is not evidence of city-scale content.
- C-05: Blender changes asset authoring, not the runtime engine. Keep Three.js and pure TypeScript game rules; do not export a single giant world GLB or replace the game with pre-rendered video.
- C-06: Historical/modern/speculative looks coexist as deliberate fictional districts and wardrobe collections. Do not claim the blend is a historical reconstruction or use a culture as shorthand for poverty, wealth, backwardness or criminality.
